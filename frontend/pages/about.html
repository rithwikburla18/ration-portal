About the Ration Portal

Ration Portal is a Government-inspired academic and portfolio project that demonstrates how Public Distribution System related citizen services can be brought together in a single digital interface.

The application was developed with a Java and Spring Boot backend, PostgreSQL database, HTML5, CSS3 and Vanilla JavaScript frontend, with authentication, administration, citizen services and production deployment.

The portal is intended for educational demonstration and is not an official Government of India website.
